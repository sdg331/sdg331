## Design & Product

**화면을 보여주는 데서 끝내지 않고, 선택의 이유까지 설명하는 작업을 지향합니다.**

| Focus | 프로젝트에서 다루는 질문 |
| :--- | :--- |
| **Problem → Flow** | 누구의 어떤 불편을 해결하며, 사용자는 어디서 시작하는가? |
| **Flow → Interface** | 지금 필요한 정보와 다음 행동을 어떻게 명확하게 보여줄까? |
| **Interface → Feedback** | 입력 오류·대기·완료·결과 미확인을 어떻게 구분할까? |
| **Prototype → Validation** | 구현한 것과 아직 검증하지 못한 것을 어떻게 나눌까? |
